# Fairview Volunteers

A small sign-up sheet for volunteer shifts in a fictional county, built to teach a planning workflow: every story goes through an intent, a spec and a plan with Claude Code before any code is written. Clone it, run `pnpm install && pnpm db:reset && pnpm dev`, and open http://localhost:3000. The full tutorial is coming; until then, `CLAUDE.md` explains how the repo is put together.
